# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

HaluEval is a hallucination evaluation benchmark for Large Language Models. It provides:
- 35K samples for evaluating LLM hallucination detection ability
- Tools for generating hallucinated samples from seed datasets
- Evaluation scripts to measure hallucination recognition accuracy
- LDA-based analysis for identifying failure patterns

## Commands

### Data Generation

Generate hallucinated samples from seed data (requires OpenAI API key in `generation/generate.py`):

```bash
cd generation
python generate.py --seed_data hotpot_train_v1.1.json --task qa --strategy one-turn
python generate.py --seed_data opendialkg.csv --task dialogue --strategy multi-turn
python generate.py --seed_data cnndm.json --task summarization --strategy one-turn
```

### Data Filtering

Filter generated samples to select the most plausible hallucinations:

```bash
cd generation
python filtering.py --task qa
```

### Evaluation

Evaluate a model's hallucination detection ability:

```bash
cd evaluation
python evaluate.py --task qa --model gpt-3.5-turbo
python evaluate.py --task dialogue --model davinci
python evaluate.py --task summarization --model gpt-3.5-turbo
```

### Analysis

Analyze topics in evaluation results using LDA:

```bash
cd analysis
python analyze.py --task qa --result ../evaluation/qa/qa_gpt-3.5-turbo_result.json --category all
python analyze.py --task qa --result ../evaluation/qa/qa_gpt-3.5-turbo_result.json --category failed
```

## Architecture

### Pipeline Flow

1. **Generation** (`generation/generate.py`): Takes seed datasets (HotpotQA, OpenDialKG, CNN/DailyMail) and uses ChatGPT to generate hallucinated counterparts using task-specific instruction prompts
2. **Filtering** (`generation/filtering.py`): Compares one-turn vs multi-turn generated hallucinations and uses ChatGPT as a judge to select the most plausible one
3. **Evaluation** (`evaluation/evaluate.py`): Presents 50% correct and 50% hallucinated answers to LLMs, asking them to classify with "Yes" (hallucination) or "No" (correct)
4. **Analysis** (`analysis/analyze.py`): Uses LDA topic modeling to identify patterns in samples the model failed to recognize

### Data Structure

Final benchmark data in `/data/` contains paired samples:
- `knowledge`: Background factual knowledge
- `question`/`dialogue_history`/`document`: The input context
- `right_answer`/`right_response`/`right_summary`: Ground truth from seed dataset
- `hallucinated_answer`/`hallucinated_response`/`hallucinated_summary`: Generated plausible but incorrect output

### Instruction Files

Each task has instruction templates in subdirectories:
- `{task}/{task}_one-turn_instruction.txt`: Single prompt for hallucination generation
- `{task}/{task}_multi-turn_instruction.json`: Multi-turn conversation for generation
- `{task}/{task}_filtering_instruction.txt`: Prompt for selecting best hallucination
- `evaluation/{task}/{task}_evaluation_instruction.txt`: Prompt for hallucination detection

### Tasks

- `qa`: Question answering (seed: HotpotQA)
- `dialogue`: Knowledge-grounded dialogue (seed: OpenDialKG)
- `summarization`: Text summarization (seed: CNN/DailyMail)
- `general`: General user queries (human-annotated, no generation pipeline)

## Hallucination Types

The generation prompts instruct ChatGPT to create 4 types of hallucinations:
1. **Misunderstanding**: Misinterpreting the question's context
2. **Factual Contradiction**: Directly contradicting the provided knowledge
3. **Specificity Error**: Correct but at wrong level of detail
4. **Reasoning Error**: Drawing conclusions not supported by the knowledge

## Key Design Notes

- **In-context knowledge provision**: Evaluation prompts include `#Knowledge#` field with ground truth facts, so models are tested on reading comprehension and logical comparison, not internal knowledge recall
- All scripts use the legacy OpenAI API format (`openai.ChatCompletion.create`)
- API key must be set directly in Python files (variable `openai.api_key`)
- Scripts use JSONL format for intermediate outputs, JSON for final data files

## Known Limitations

- Hallucinations are generated by ChatGPT, so they may reflect ChatGPT-specific error patterns rather than diverse hallucination types
- The 4-type instruction pattern may produce artificial errors that models can detect via pattern matching
- ChatGPT-as-judge in filtering may introduce errors in sample selection
- See `ww_custom/halueval_analysis.md` for detailed analysis (Korean)

# FavaBench 데이터셋 (`fava_data/`) 통계 분석 결과

`annotations.json` (평가 및 검증용)과 `training.json` (학습용) 두 파일에 대한 총 건수, 분야별 분포, 정답/오답 비중을 분석한 결과입니다.

## 1. `annotations.json` (전문가 태깅 데이터)

이 파일은 인간 전문가가 섬세하게 환각(에러) 태그를 붙여둔 핵심 벤치마크/파인튜닝 데이터입니다.

- **총 데이터 건수:** 460건
- **분야별(Domain) 분포 비중:**
  - `webnlg` (웹 문서/위키 요약): 182건 (39.6%)
  - `instruction-following` (지시 수행): 140건 (30.4%)
  - `open-assistant` (대화형 에이전트): 138건 (30.0%)
- **정답(Correct) vs 환각(오답) 비중:**
  - **정답 (태그 없는 클린 데이터):** 153건 (33.3%)
  - **환각 (오류 태그 포함):** 307건 (66.7%)
- **환각 유형별 세부 빈도 (중복 허용):**
  - `Entity` (고유명사/개체 오류): 187건
  - `Subjective` (주관적 개입): 91건
  - `Unverifiable` (검증 불가): 87건
  - `Contradictory` (모순): 69건
  - `Invented` (완전한 지어냄): 60건
  - `Relation` (관계/인과 오류): 25건

## 2. `training.json` (대규모 사전학습용)

- **총 데이터 건수:** 30,073건
- **특징:** 이 파일은 세부적인 xml 태그가 전혀 포함되어 있지 않은(0%) 클린 텍스트 또는 다른 형태의 원시 텍스트 모음입니다. 따라서 세밀한 '판사 모델' 파인튜닝 시에는 이 3만건의 데이터보다는, 앞서 언급된 **460건의 `annotations.json` 구조(태그가 있는 데이터)를 본따서 증강/응용하는 것**이 목적에 부합합니다.
